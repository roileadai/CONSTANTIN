## 8) 7 Гипотез-проектов — карточки (MAX-детализация)

### Проект #1 — CONSTANTIN Memory
**Тэглайн:** *Your Claude Code never forgets.*

**Проблема:** Claude Code / Cursor / Codex теряют контекст между сессиями. Разработчики тратят 30-60 мин/день на «объясни снова где мы остановились». `claude-mem` (95k★) и `ai-memory` (10k★) доказали спрос, но они — open-source без UX/монетизации.

**Аудитория:** 47% US девов уже на Claude Code [5] → ~2-3M активных юзеров. Платящая ниша: соло-девы, indie hackers, фрилансеры на Claude Max ($200/мес [27]) — они уже платят за постоянство.

**Решение:**
- CLI `npm i -g constantin` → хуки в `~/.claude/` → авто-компрессия каждой сессии в `CONSTANTIN.md` (как у Notion memory page [6])
- Инъекция релевантного контекста в следующую сессию (RAG + embeddings)
- Handoff между Claude ↔ Cursor ↔ Codex (как `ai-memory` задумал)
- Dashboard: timeline сессий, поиск по «что мы делали 3 дня назад?»

**MVP 2-3 недели:**
